================================================================================
PAYROLL (settings, salary structures, assignments, runs, payslips) — UI GUIDE (for the UI designer / frontend)
================================================================================
Who      : Payroll manager / owner (admin side); employees (payslips); super admin (statutory rates)
Apps     : Web panel; employee app (payslips)
Details  : request/response fields are in admin.txt, employee.txt, super-admin.txt, usecase.txt
Tags     : urls.py marks each endpoint  #SU super admin, #A admin side,
           #E employee, perm: <code> = permission the caller needs.
           Show admin screens only when my-profile data.permissions contains
           the code (organization owner has every code).

SETUP ORDER (show as a checklist on the Payroll page)
  1. Settings                settings/ (cycle start day, salary basis, overtime,
                             late deduction on/off + multiplier, payslip mode)
  2. Statutory settings      statutory-settings/ (PF / ESI / PT / LWF flags)
  3. Components              components/list|create/
  4. Structures              structures/list|create|detail|update|deactivate/
  5. Salary assignments      assignments/list|create|update|bulk-assign|bulk-close/
                             (effective_from must be a payroll cycle start date)
  6. Runs                    runs/preview -> create -> generate -> finalize
SCREENS
  - Run page: records/list/ with review flags, records/update-deductions/
    (manual TDS / other deductions, recompute), payments/record|bulk-record|list/,
    payslips/download/.
  - Calculator: calculator/ (simulate a payslip).
  - Employee: my/payslips/, my/payslips/detail/, my/payslips/download/, my/salary/.
  - Super admin: statutory-rate-configs/*, statutory-slabs/*.
RULES TO SHOW
  - Finalize is blocked by ERROR records and unresolved review flags; explain why.
  - Missing attendance days set requires_review: mark absent (attendance) then recompute.
  - Salary revision = close old assignment, create a new one.
ACCESS (batch 2)
  - Payroll menu: show when the user has any of payroll.view_all,
    payroll.generate, payroll.finalize, salary.assign.
  - Setup (settings, statutory): settings.manage or payroll.generate.
  - Components, structures, assignments, calculator: salary.assign.
  - Runs: generate / recompute = payroll.generate; finalize and salary
    payments = payroll.finalize; view = payroll.view_all.
  - Never team-scoped. Employees use the my/* endpoints.
CTC (batch 3)
  - Structure form: tick one earning as "Balancing (takes the rest)".
    Use "% of gross" (percentage with no base) for Basic.
  - Salary assignment form: Annual CTC or Monthly gross (one input + a
    toggle). Show the live breakup from calculator/ (ctc_breakup) before saving.
  - Settings: "CTC includes employer PF / ESI" switch.
  - Revision = close old assignment, create a new one with the new package.

LATE DEDUCTION (batch 7)
  - Settings: "Late mark deduction" switch (late_deduction_enabled) and
    "Multiplier" (late_deduction_multiplier, default 1.00) next to Overtime.
    Help text: "Late minutes after grace x per-minute salary x multiplier".
  - Preview / record tables: add a "Late (min)" column (late_minutes).
  - Payslip: LATE line is a normal deduction row ("Late Deduction").
  - Calculator: "Late minutes" number input -> late_minutes.

PF CONTRIBUTION TYPE + VPF (batch 8)
  - Statutory settings: "PF contribution type" dropdown (Standard / Company
    specific / Voluntary PF). Show pf_rate_info.note under it (e.g. warns when
    Company specific is chosen but no company rates exist yet).
  - Employee form (HR): "Voluntary PF %" number field (vpf_percentage, 0-88),
    shown when the organization's type is VPF.
  - Payslip / record views: a "VPF" deduction row appears like any other line.
